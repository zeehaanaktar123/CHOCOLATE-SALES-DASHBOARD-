# CHOCOLATE-SALES-DASHBOARD-
1. A Chocolate Company Dataset is cleaned like removing duplicates, adjust spaces, adding and removing columns in excel using power query then transferred it to MySQL for analyze and identifying connections between data.
2. Lastly it transferred to Power BI for making a sales Dashboard for proper insights. 
3. Qualitative and quantitative queries like Sales trend over time, Top 5 most selling Products, Product sales based on Country, Sales persons contribution in the total sales amount are answered with proper visualization.
